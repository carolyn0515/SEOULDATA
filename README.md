## 프로젝트 개요

서울의 관광 수요는 명동·홍대·이태원·동대문 등 특정 권역에 과도하게 집중되어 있다. 이로 인해 한쪽에서는 **오버투어리즘**이, 다른 한쪽에서는 **소외 상권 침체**가 동시에 발생한다. 본 프로젝트는 이 두 문제를 분리된 현상이 아니라 **동일한 도시 흐름 구조의 비대칭이 만들어낸 하나의 문제**로 보고, `Hidden Spot`이라는 매개 개념을 통해 통합적으로 해결하는 데이터 기반 프레임워크를 제안한다.

## 핵심 아이디어: Hidden Spot

관광객은 단일 지점이 아니라 **교통·상업·문화·보행 환경이 결합된 복합적 도시 경험**을 소비한다. 따라서 관광 수요 분산은 "가까운 곳"이 아니라 **"비슷한 경험을 제공하는 곳"**으로 유도되어야 한다.

Hidden Spot은 다음 세 조건을 동시에 만족하는 공간으로 정의한다.

1. 혼잡 지역과 **도시 기능이 유사**할 것
2. **소비 맥락이 유사**할 것
3. 현재 **과도한 혼잡이 발생하지 않을 것**

## 연구 가설

| 가설 | 내용 |
|---|---|
| H1 | 관광 혼잡은 특정 도시 기능과 소비 구조의 과잉 응집 현상이다 |
| H2 | 혼잡 지역과 유사한 도시 경험 구조를 가진 비혼잡 지역은 Hidden Spot으로 기능할 수 있다 |
| H3 | Hidden Spot 기반 관광 수요 재분산은 소외 상권 활성화 정책과 연결될 수 있다 |

## 분석 프레임워크 (6 STEP)

```
STEP 1. 데이터 기반 혼잡 탐지        → Sensor-aware OTI + Fruin LOS
STEP 2. 도시 경험 벡터화              → X(도시 기능) / C(소비 행동) 분리
STEP 3. Hidden Spot 1차 후보 탐색    → Cosine similarity + Time constraint
STEP 4. 로컬 상권 기반 정책 필터링   → 서울시 로컬브랜드 상권 연계
STEP 5. Facility Location 최적화     → Greedy Algorithm + Elbow Point
STEP 6. 정책 활용                     → 소외 상권 연계 분석 및 회랑형 정책 제안
```

## 주요 방법론

**Sensor-aware Overtourism Index (OTI)**
기존 행정구역 평균 밀도 방식의 한계를 보완하기 위해, 센서 유형별 유효 관측 면적(전파 7,850㎡ / 영상 6.25㎡)을 반영하여 혼잡을 재정의. Fruin LOS C/D 경계값(0.72명/㎡)을 혼잡 임계점으로 설정.

**X / C 벡터 분리**
- `X (도시 기능 벡터)`: 교통·상업·문화·관광·보행 환경 등 공간이 제공할 수 있는 활동
- `C (소비 행동 벡터)`: 내·외국인 카드 소비 데이터 기반 업종별 소비 비율

**Facility Location 기반 대표 후보 최적화**
Top-K 방식의 한계(동일 공간 반복, hotspot 편중, coverage 불균형)를 극복하기 위해 representative set selection 문제로 재정의. Submodularity와 Monotonicity를 활용한 Greedy 알고리즘 적용. Elbow distance 기반으로 최적 K=21 선정.

## 핵심 결과

**혼잡 메커니즘 검증 (H1)**
- Random Forest ROC-AUC 0.9529 vs Logistic Regression 0.9069
- 상호작용 피처 추가 시 LRT p<0.001로 유의한 모델 개선
- 관광음식 × 시간대 교호작용 OR=3.96 확인

**Hidden Spot 도출 (H2)**
- 61,622개 pair에서 44개 공간 후보 → 최종 **21개 Hidden Spot** 선정
- 서울 전체 혼잡 패턴의 **73.6%** 커버, 평균 유사도 0.7341
- 5개 클러스터로 유형화: 교통 접근형 / 생활 상업형 / 복합 상권 다양성형 / 고밀도 관광 소비형 / 관광·역사 잠재형

**소외 상권 연계 (H3)**
- 매출침체(40%) + 점포감소(30%) + 폐업압력(30%) 기반 소외도 점수 산정
- 22개 소외상권 후보지 도출, Activation Readiness Score 상위 10개 우선 연계 상권 선정
- Hidden Spot ↔ 소외상권 최적 연계 거리: **1~1.5km (생활권 회랑)**

## 정책 제안: 3가지 회랑형 전략

| 유형 | 거리 구간 | 대표 상권 | 전략 |
|---|---|---|---|
| **청동회랑형** | 초근접 도보권 (~500m) | 청계천공구상가, 테크노상가, 평화시장, 동대문문구완구거리 | 도심 특화 상권을 도보형 관광·소비 회랑으로 연결 |
| **골목숨결형** | 생활권 (1~1.5km) | NH농협은행 보광동지점, 노량진역 6번 | 생활형 골목상권으로 확장하는 스며듦 코스 |
| **번짐생활형** | 권역형 (2km 이상) | 숭인시장, 장위전통시장, 구반포역, 원신초등학교 일대 | 대중교통 기반 환승형 확장 회랑 |

## 연구의 의의

본 연구는 관광 혼잡과 소외 상권 침체를 통합적으로 해석한 첫 시도다. 서울 관광을 **"어디가 붐비는가"**의 문제에서 **"어떻게 도시 전체로 흐르게 할 것인가"**의 문제로 전환한다. 모든 threshold(유사도, 시간, 거리, K)를 자의적으로 고정하지 않고 데이터 분포와 coverage-quality tradeoff 기반으로 실험적으로 탐색하여 방법론적 자의성을 최소화했다.

## 한계 및 향후 과제

정적 시점 기반의 구조 분석에 가까우며, 실시간 이동 경로·SNS 리뷰·계절성/이벤트 데이터가 추가되면 동적 모델로 확장 가능. Hidden Spot 기반 추천이 실제 방문·체류·소비 전환으로 이어지는지에 대한 실증 검증과 회랑형 정책의 시범 운영 효과 측정이 향후 과제로 남는다.
