# SEOULDATA — 서울시 관광 혼잡 분석 및 분산 정책 제안

서울시 빅데이터 캠퍼스 분석 대회 출품작.
**관광 혼잡 타겟 지표(OTI, Overtourism Index)** 를 직접 설계하고, 이를 기반으로 관광객 분산 정책을 데이터로 제안한 프로젝트입니다.

> "관광객을 단순히 '많고 적음'으로 보는 것이 아니라, **공간의 수용 가능성** 관점에서 다시 정의한다."

---

## 1. Project Overview

### Problem

서울 주요 관광지의 과밀 문제는 시민 생활권 침해, 외국인 관광 만족도 저하, 도시 기능 저하로 이어지고 있음.
그러나 기존 혼잡 분석은 **단순 관광객 수**에 의존해 다음과 같은 한계가 있음:

- 동일한 관광객 수라도 **공간의 수용량**에 따라 체감 혼잡도가 다름
- 상업·주거·공공 등 **도시 기능 구조**가 다른 지역을 동일 기준으로 비교 불가
- **센서 관측 범위**의 차이로 같은 데이터도 다른 의미를 가짐

### Approach

위 한계를 해소하기 위해 **OTI(Overtourism Target Index)** 를 직접 설계.
센서 관측 범위·공간 밀도·도시 기능 구조를 함께 반영한 다차원 혼잡 지표.

## 2. Data Sources

여러 공공 데이터를 결합해 분석 베이스 테이블 구축:

| 데이터 | 출처 | 활용 |
|---|---|---|
| 서울시 생활인구 (관광객) | 통신사 기반 데이터 | 시·공간별 관광객 추정 |
| 관광 서포터 데이터 | 서울시 빅데이터캠퍼스 | 관광 행동·체류 패턴 |
| 공공데이터 (도시 기능, 공간) | 서울시 / 공공데이터포털 | 도시 기능 구조 분류 |

분석은 **서울시 빅데이터캠퍼스를 직접 오가며** 보안 정책을 준수하여 수행. 외부 반출 없이 분석용 데이터를 생성·관리하는 과정에서 데이터 거버넌스의 중요성을 체감.

---

## 3. OTI (Overtourism Target Index) Design

### 설계 원칙

단순 관광객 수가 아닌, **"공간이 감당 가능한 한계 대비 실제 부하"** 를 표현하는 지표.

OTI는 다음 세 축을 함께 반영:

1. **센서 관측 범위 보정** — 센서 커버리지에 따른 측정 편차 제거
2. **공간 밀도** — 면적 대비 인구 부하 정량화
3. **도시 기능 구조** — 상업·주거·관광 기능 비중에 따른 임계값 차등화

### 검증 절차

지표가 단순 가설이 아닌 분석 도구로 작동하도록 다음 단계를 거침:

- **Threshold 검증**: 임계값을 어떻게 정해야 정책적으로 의미 있는 구간이 나오는지 분석
- **선형/비선형 분석**: 지표와 실제 혼잡 체감의 관계가 단조 증가인지, 임계 효과가 있는지 검증
- **설명 가능성 확보**: 각 구성 요소가 결과 OTI 값에 어떤 방향·강도로 기여하는지 정리

## 4. Analysis Pipeline

```
[Raw Data Collection]
        ↓
[데이터 정제 & 결합]
   - 시공간 단위 정렬
   - 생활인구 + 관광 + 공공데이터 join
        ↓
[EDA]
   - 지역·시간대별 분포 분석
   - 도시 기능별 패턴 차이 식별
        ↓
[OTI 지표 설계]
   - 센서 관측 범위 보정
   - 공간 밀도 정규화
   - 도시 기능 가중 반영
        ↓
[지표 검증]
   - Threshold 분석
   - 선형/비선형 관계 검증
   - 설명 가능성 확인
        ↓
[정책 활용 분석]
   - 분산 가능 지역 식별
   - 시간대별 우회 전략 도출
```

## 5. Key Findings

(분석 결과 요약 — 실제 수치는 본인이 채워주세요)

- **공간 밀도 vs 도시 기능**: 동일 관광객 수에서도 도시 기능 비중에 따라 체감 혼잡도가 크게 다르게 나타남
- **시간대 편향**: 특정 시간대의 과밀은 단순 관광객 분산이 아닌 **시간대 분산**으로 더 효과적으로 해결 가능
- **정책 제안**: OTI 기반으로 분산 가능 후보지·시간대를 정량적으로 도출

## 8. What I Learned

이 프로젝트의 가장 큰 수확은 **"좋은 지표는 직관이 아니라 검증 과정에서 만들어진다"** 는 깨달음이었습니다.

- 처음에는 "관광객이 많은 곳이 혼잡한 곳"이라는 직관에서 출발했지만, 면적·도시 기능을 반영하자 같은 관광객 수가 전혀 다른 의미를 가진다는 것을 확인

- 비전공자 팀원과의 협업에서 **분석 근거를 어떻게 설명 가능한 형태로 전달할 것인가** 가 분석가의 핵심 역량임을 배움
